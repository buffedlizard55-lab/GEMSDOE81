      <article class="panel">
        <p class="eyebrow">What is being measured</p>
        <h2>Fault prediction, not geothermal-vent labels</h2>
        <p>The official task asks for pixelwise fault predictions in the GeoDAWN region. The competition's known fault catalogue is incomplete; public-label recovery is therefore only a proxy for discovery of expert-identified unmapped faults.</p>
        <a class="text-link" href="https://www.drivendata.org/competitions/306/competition-doe-gems/page/967/">Read the official problem, metric and file format ↗</a>
      </article>
      <article class="panel panel-dark">
        <p class="eyebrow">Current test candidate</p>
        <h2>Magnetic–gravity edge concordance</h2>
        <p>Ranked first for a future test: compare multiscale magnetic and isostatic-gravity edge orientation/coherence. It is a hypothesis only—not implemented, validated, or selected for submission.</p>
        <a class="text-link light" href="hypotheses.html">See ranked hypotheses and confounders ↗</a>
