## First test (rank 1), if blockers are cleared

**Frozen question:** Does a multi-scale magnetic–gravity edge-concordance feature, computed from documented competition-provided layers without using hidden or visible catalogue pixels, improve pooled off-catalogue `HOLDOUT-DTI` over the current same-budget best emission rule under whole-segment buffered spatial holdout?

**Do not claim this test ran.** The steps below define a protocol; the shared evaluator must be inspected and used before any code is added.

1. Identify layer names, units, nodata masks and spatial support from official feature metadata and the shared cached stack. No hand-assigned band indices. Hash inputs and evaluator version.
2. Partition catalogued fault *segments* into spatial blocks. For every fold, withhold whole segments and a documented spatial buffer. Build every catalogue-derived feature from visible faults only; exclude hidden segments plus their buffer from training/feature construction. Mask visible segments pixel-exactly wherever the evaluator requires. Freeze folds before inspecting results.
3. Run each primitive layer/transform alone as a leakage canary on the held-out segments. Report fold-level AUC; any AUC >0.90 is suspected leakage pending investigation, not a useful performance result. Use the same buffered split and no hidden labels in normalization/threshold selection.
4. Compare controls and candidate at matched output pixel budgets. Score with the shared evaluator's pooled distance-weighted Tversky: alpha=0.2, beta=0.8, triangular kernel support 300 m. Report evaluator version, withheld-positive count and 95% CI; the CI should resample spatial blocks/segments, not individual correlated pixels. Do not substitute the mean of fold scores for pooled DTI.
5. Test novelty at two stages: (a) continuous candidate surface vs every registry surface, using rank correlation inside common valid footprint; (b) selected final dots vs each registry's dots, with the specified 3 px neighborhood. Stop and record a duplicate if either threshold in the project protocol is exceeded.
6. Promote only if the candidate exceeds the current best under the frozen protocol with uncertainty reported, passes canary/duplicate tests, and does not win merely by emitting more mass. This license is for candidate-file generation only; it is not an organizer score and does not select a weekly slot.

## Interpretation limits

- The official problem describes the target as faults, and the competition's test labels are expert-identified faults absent from the current public USGS database. A visible-label holdout is therefore proxy validation, not proof of discovery performance.
- The official USGS GeoDAWN release says the survey includes airborne magnetic and radiometric data, and its geophysical context supports investigation of subsurface structure; it does not establish that any particular edge is a fault or a geothermal system.
- The user-provided site list includes many related attempts. Names alone cannot prove algorithmic uniqueness. Read their accessible methods and compare actual rasters before any uniqueness claim.
- If the lane is intended to be one of the prior site's specific methods, it must be identified explicitly. Until then, the cross-scale magnetic–gravity proposal is only a transparent test candidate, not a run or chosen submission.
