How to submit a GEMS prediction

!

Current state

NOT READY — no download file

There is no GEMSDOE81 TIFF to download. A file is publishable only after the local candidate has passed holdout, duplicate, and byte-level format checks. Do not submit an older project's file as a replacement.

Once this page marks a candidate READY

  1. Download the clearly labeled candidate GeoTIFF from the Executive summary page. Confirm the displayed candidate name, short note, SHA-256, validation receipt, and status before using it.
  2. Open the official DOE GEMS competition and sign in to the account/team that is authorized to submit.
  3. Open the competition submission form and choose the downloaded single-band .tif file in “File to submit.” The official format is one GeoTIFF, or a ZIP containing one GeoTIFF; use the offered TIFF directly.
  4. Enter the published unique submission name/comment in the optional Note field. The project must keep this note at or under 140 characters. Do not use a projected or holdout result as a claimed score.
  5. Review the filename and note, then submit in DrivenData. Save the submission-page receipt. Only that receipt can establish an organizer-confirmed score for that submission.

Why there is no download button yet

The data page is login-gated, and this checkout currently has no competition data, shared evaluator/writer, or registry rasters. Without the official grid metadata and a validated holdout result, any TIFF made here could be format-invalid, scientifically untested, or a duplicate. A blank/zero raster or an older team's raster would not satisfy the project's discovery and uniqueness goals.

Official submission format: projected CRS EPSG:32611, 100 m resolution, same bounds/grid as training, a single float32 layer, confidence values between 0 and 1, and null/NaN outside the data bounds. Always verify against the actual official sample/training raster rather than copying dimensions from another project page.
