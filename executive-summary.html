Executive summary

Submitting a GEMS GeoTIFF — only after promotion

The upload itself is simple. The hard part is establishing that the exact file is scientifically justified, unique under the project protocol, and valid on the official grid.

Exact submission steps for a promoted artifact

  1. Confirm the release decision. On the project home page, check that both the exact filename and SHA-256 are listed, and that the status explicitly says OK TO SUBMIT: YES. A format PASS alone is not enough.
  2. Download the exact file. Use the site's direct TIFF link (or a ZIP containing exactly one TIFF if provided). Compare the local file's SHA-256 with the on-page receipt.
  3. Open the official competition. Sign in to DrivenData and open the GEMS Prize Challenge. The data and submission form require the enrolled account.
  4. Choose the upload file. Select a single-band GeoTIFF (.tif), or a ZIP with one GeoTIFF. The official problem description specifies the grid and pixel contract.
  5. Enter the name and note. Use the unique submission name and the short note (at most 140 characters) published with that candidate. Do not describe an unmeasured score as a result.
  6. Check the slot and submit. Follow the remaining weekly-slot count shown on the submission page. The project does not spend a slot or automatically select a candidate.
  7. Save the receipt. Preserve the actual submission-page result/score, timestamp, submission identifier, and filename. Label a score ORGANIZER-CONFIRMED only when that receipt identifies the exact uploaded artifact.

Grid and values

  • one band, float32;
  • EPSG:32611, 100 m, exact training-grid bounds/shape/transform;
  • inside the valid footprint, values are finite and within [0,1];
  • outside the footprint, use null/NaN as required by the official format.

Science and release

  • buffered whole-segment holdout beats the frozen local best;
  • every feature passes the leakage canary;
  • surface and final dots pass registry-correlation and overlap checks;
  • file, hash, run card, name, and note all match.
